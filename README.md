# Machine Learning Course

Coursework and assignments from a machine learning course, covering classical models and neural networks implemented from first principles.

## Contents

| Project | Description | Stack |
|---|---|---|
| [XGBoosting.ipynb](XGBoosting.ipynb) | XGBoost classifier with early stopping, learning curves and feature importance | XGBoost, pandas |
| [XGBoosting Model.ipynb](XGBoosting%20Model.ipynb) | XGBoost on Iris: grid search, tree-depth and subsampling studies, regression | XGBoost, scikit-learn |
| [ML-Homework-53](ML-Homework-53) | Forward pass and backpropagation: manual derivation, NumPy MLP, PyTorch autograd | NumPy, PyTorch |

## Setup

Each project is a self-contained Jupyter notebook. Where a project folder includes a `requirements.txt`, install its dependencies before running:

```bash
pip install -r <project>/requirements.txt
```
